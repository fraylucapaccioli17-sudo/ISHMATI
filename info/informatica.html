📌 ¿Qué es Informática Administrativa?

La Informática Administrativa es una disciplina que combina los conocimientos de administración de empresas con las tecnologías de la información. Su objetivo es optimizar procesos, gestionar recursos y tomar decisiones estratégicas mediante el uso de sistemas informáticos, bases de datos y herramientas digitales.

📌 En este proyecto presentaremos:

🌐

Creación de páginas web

Aprenderemos HTML, CSS y JavaScript para diseñar sitios web profesionales y responsivos.
🎮

Juego en HTML

Desarrollaremos juegos interactivos usando HTML, CSS y JavaScript para poner a prueba nuestra lógica.
🗺️

Mapa interactivo

Crearemos mapas digitales con enlaces y zonas clickeables para mostrar regiones de Morelos.
